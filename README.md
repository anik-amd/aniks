# anik

Personal portfolio site, deployed to Cloudflare Pages at <https://anik.pages.dev>.

This repository currently contains a placeholder page used to reserve the Pages project
name. The real site (Astro, statically pre-rendered) replaces it next.

## Hosting

- Source: GitHub (private for now)
- Build + deploy: Cloudflare Pages, Git integration
- Build command: `exit 0`
- Build output directory: `/`

Once the Astro app lands, these become `npm run build` and `dist`.
